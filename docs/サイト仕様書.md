## 1. サイトの全体像

このウェブサイトは **1ページ** にすべての情報がまとまっています。
上のメニュー（ヘッダー）をタップすると、そのセクションまでスクロールして移動します。

### ページの構成（上から順番に）

| 順番 | セクション名 | 内容 |
|------|-------------|------|
| 1 | ヒーロー | トップの大きなメッセージ「色の力で、心に寄り添う」 |
| 2 | ニュース & お知らせ | 新着情報（今は仮のデータ） |
| 3 | イベントカレンダー | イベント情報（今は仮のデータ） |

| 5 | 選ばれる3つの理由 | お客様に選ばれる理由を3つ紹介 |
| 6 | サービス | 4つのサービス紹介 + セッションの流れ |
| 7 | 料金 | 各メニューの料金表 |
| 8 | よくある質問（FAQ） | タップすると回答が開く形式で5問 |
| 9 | プロフィール | 名前・経歴・資格・想い |
| 10 | ギャラリー | 活動写真（今はイメージ画像） |
| 11 | Instagram | Instagramの投稿を埋め込み表示 |
| 12 | お問い合わせ | フォーム + 所在地・営業時間・Instagram |

### ヘッダー（メニュー）

画面上部に固定されるメニューバーです。
- PC: 横並びでリンクが表示されます
- スマホ: 右上のハンバーガーメニュー（三本線）をタップすると開きます

**メニュー項目**: ホーム / お知らせ / イベント / サービス / 料金 / プロフィール / お問い合わせ

### フッター

ページ最下部。ナビゲーションリンク、Instagramリンク、コピーライトが表示されます。

### LINE公式アカウントボタン

画面右下に常に表示される緑色のボタンです。
タップすると LINE公式アカウント（@657fiibx）に飛びます。

## 4. サイトの見かた・アクセス方法

### サイトURL
**https://gohho113.github.io/my-mother-s-website/**

スマホのブラウザ（Safari, Chromeなど）でこのURLを開くと見られます。

### ホーム画面に追加する方法（iPhone）
1. Safariで上のURLを開く
2. 画面下の共有ボタン（四角から矢印が出ているアイコン）をタップ
3. 「ホーム画面に追加」をタップ
4. 名前を「Rainbow Drops」にして「追加」をタップ

これでホーム画面からアプリのようにアクセスできます。

### ホーム画面に追加する方法（Android）
1. Chromeで上のURLを開く
2. 右上の「︙」（メニュー）をタップ
3. 「ホーム画面に追加」をタップ
